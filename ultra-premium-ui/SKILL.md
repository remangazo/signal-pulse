# Ultra-Premium UI Skill

## Purpose
This skill targets "Awwwards" or "FWA" level design quality for business landings. It focuses on visual shock, interactive delight, and flawless execution of modern design trends.

## Core Rules
1. **Interactive Presence**: Every element should feel reactive. Use mouse position, scroll velocity, and click states to trigger visual feedback.
2. **Typography as Art**: Use large, bold, or elegantly thin typography as a core structural element, not just for reading.
3. **Motion Design**: Animations should be buttery smooth, using custom Bezier curves or spring physical models.
4. **Tailwind Mastery**: Use arbitrary values and complex grid/flex configurations to achieve unique layouts.

## Techniques
- **Magnetic Elements**: Calculate distance from mouse to element and apply translate based on proximity.
- **Horizontal Scroll Sections**: Divert vertical scroll to horizontal for immersive galleries.
- **Glassmorphism & Frosted Effects**: Deep layering using backdrop-blur and subtle borders.
- **Custom Shaders (R3F)**: Use custom GLSL for backgrounds (liquid metal, noise gradients).
