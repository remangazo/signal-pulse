# SignalPulse — Brand Identity Guide

## Naming
- **Product name**: SignalPulse
- **Tagline**: *"Your next customer is commenting somewhere."*
- **Subtagline**: *"AI-powered lead discovery from social conversations."*

## Color Palette

| Token | Hex | Usage |
|---|---|---|
| **Pulse Violet** | `#7C3AED` | Primary brand color, buttons, links |
| **Pulse Cyan** | `#06B6D4` | Secondary, gradients, highlights |
| **Pulse Amber** | `#F59E0B` | Accent, badges, stars, alerts |
| **Signal Green** | `#10B981` | Success, lead score high |
| **Deep** | `#09090B` | Background (dark) |
| **Surface** | `#18181B` | Cards, sections |
| **Border** | `#27272A` | Borders, dividers |
| **Foreground** | `#FAFAFA` | Primary text |
| **Muted** | `#A1A1AA` | Secondary text |
| **Error** | `#EF4444` | Errors, low score |

## Typography
- **Headings**: Inter (sans-serif), bold, tight leading
- **Body**: Inter, regular, comfortable leading
- **Code/Monospace**: JetBrains Mono (for examples/API)

## Logo
- Text-based: **SignalPulse** in bold Inter
- Optional icon: A pulse/signal wave icon next to text
- Color: Pulse Violet gradient to Pulse Cyan

## Voice & Tone
- **Confident but not arrogant**: "We find people already asking for what you sell."
- **Direct, no fluff**: "One lead closes and it pays for itself."
- **Developer-friendly**: Reference APIs, integrations, technical accuracy
- **Outcome-focused**: Leads delivered, customers closed, not features listed

## Design Principles
1. **Dark-first**: Dark mode as default, light mode secondary
2. **Glassmorphism**: Subtle backdrop blur on floating elements
3. **Gradient hero**: Animated plasma-like gradients in hero section
4. **Subtle animations**: Fade-in on scroll, micro-interactions
5. **Spacious**: Generous padding, lots of breathing room
6. **One CTA**: Clear single action per section

## Imagery Style
- Use screenshots of the product (dashboard, leads table)
- Testimonials with real photos and company logos
- Clean illustrations where needed, prefer UI screenshots over stock
